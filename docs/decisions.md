# Architecture Decisions

## ADR-001: React

Decision:
Use React with Vite for the frontend.

Reason:
Component-based architecture and suitable ecosystem.

---

## ADR-002: Express

Decision:
Use Node.js with Express for the backend.

Reason:
Simple REST API architecture and suitable for the project.

---

## ADR-003: MySQL

Decision:
Use MySQL as the primary database.

Reason:
TaskFlow contains relational entities such as users,
tasks and categories.

---

## ADR-004: REST API

Decision:
Use REST API between frontend and backend.

Reason:
Simple and appropriate for the application architecture.
