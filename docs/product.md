# TaskFlow Product Specification

## Overview

TaskFlow is a web application for managing daily tasks
and schedules through a calendar-based interface.

## Problem

Users often manage tasks through multiple applications,
notes and calendars. TaskFlow provides a single place
to organize tasks and schedules.

## Target Users

- Students
- Individual users

## Main Value

TaskFlow allows users to:

- Plan their day
- Track task progress
- Manage deadlines
- Organize tasks by category
- View tasks through a calendar

## MVP

The MVP focuses on:

1. Authentication
2. Task management
3. Calendar
4. Categories
5. Priority
6. Status
7. Search
8. Filtering
9. Dashboard
